# Гимнастика для глаз — приложение для Windows и Android

Та же гимнастика, что и на странице, но как настоящее приложение:

- **Упражнения** — круг, квадрат, горизонталь, вертикаль, диагональ, восьмёрка и полный комплекс.
- **Камера** следит, чтобы двигались только глаза: предупреждает о движении головы, проверяет, ведёт ли взгляд за точкой,
  показывает курсор взгляда после настройки по 9 точкам, начисляет очки и ведёт рейтинг.
- **Перерывы 20-20-20** — каждые 20 минут работы (можно 30, 45 или 60) приложение напоминает 20 секунд посмотреть вдаль,
  на 6 метров и дальше. Конец перерыва отмечается звуковым сигналом, на экране — счётчик перерывов за день.
- **Windows** — значок в трее у часов, запуск вместе с Windows, пауза на час. Таймер считает только время за компьютером:
  если вы отошли больше чем на 5 минут, заблокировали экран или компьютер спал, отсчёт начинается заново.
- **Android** — напоминания приходят системными уведомлениями, даже когда приложение закрыто. Приложение ставит их
  на 12 часов вперёд и дописывает каждый раз, когда вы его открываете или нажимаете на напоминание.
- **Без интернета.** Распознавание лица встроено в приложение. Видео с камеры обрабатывается только на устройстве и никуда не отправляется.

Гимнастика тоже считается перерывом: после неё отсчёт до напоминания начинается заново.

## Установка на Windows

1. Запустите `EyeGym-Setup-1.0.0.exe`. Windows может показать «Windows защитил ваш компьютер» — так бывает со всеми программами
   без платной цифровой подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
2. После установки приложение откроется само, а на рабочем столе и в «Пуске» появится ярлык «Гимнастика для глаз».
3. **Камера.** Если она не включается: *Параметры → Конфиденциальность и защита → Камера* → включите «Доступ к камере»
   и «Разрешить классическим приложениям доступ к камере». Закройте Zoom, Teams и другие программы, которые держат камеру.
4. **Уведомления.** Если напоминания не видны, проверьте *Параметры → Система → Уведомления* (и режим «Не беспокоить»).
   Можно включить в приложении «Сразу открывать перерыв вместо уведомления» — тогда окно с отсчётом само появится поверх остальных.
5. **Трей.** Крестик окна не закрывает программу, а сворачивает её к часам — иначе напоминания не придут.
   Значок может прятаться под стрелкой «^»; его можно перетащить на панель задач. Правый щелчок по значку — меню:
   перерыв сейчас, интервал, пауза на час, автозапуск, выход.

Портативная версия запускается без установки, но Windows может не показывать её уведомления, поэтому у неё по умолчанию включено
«Сразу открывать перерыв». Автозапуск у неё выключен по умолчанию, а настройки и рейтинг хранятся отдельно от установленной версии.
При удалении программы через «Параметры → Приложения» она убирается и из автозагрузки.

## Установка на Android

1. Откройте на телефоне страницу *Releases* вашего репозитория (войдите в GitHub в браузере телефона) и скачайте `EyeGym-Android-N.apk`.
2. Откройте скачанный файл. Android попросит разрешить установку из этого источника (браузера) — разрешите и нажмите «Установить».
   Google Play Защита может предупредить о неизвестном приложении — выберите «Всё равно установить».
3. При первом запуске разрешите уведомления. Доступ к камере приложение спросит, когда вы включите переключатель «Камера».
4. На некоторых телефонах (Xiaomi, Huawei, Honor, Samsung) система усыпляет фоновые приложения. Чтобы напоминания приходили вовремя,
   в настройках приложения отключите для него экономию батареи. Если телефон спал, напоминание может прийти сразу после разблокировки.

Новые версии ставятся поверх старых без удаления — рейтинг и настройки сохраняются.

## Как поменять приложение

Отредактируйте файл прямо на GitHub (значок карандаша) — после *Commit changes* сборка запустится сама, и в *Releases* появятся новые файлы.

- `www/index.html` — вся гимнастика, трекер и панель перерывов (общая для Windows и Android).
- `electron/main.js` — окно, трей, уведомления и автозапуск на Windows; `electron/scheduler.js` — таймер перерывов.
- `scripts/vendor.mjs` — кладёт в приложение библиотеку MediaPipe и модель лица.
- `scripts/android-patch.mjs` — разрешения камеры и уведомлений для Android.
- `package.json` — номер версии (`"version"`) и настройки установщика.

### Сборка на своём компьютере (для разработчиков)

Нужен Node.js 20 или новее.

```bash
npm install
npm test            # проверки таймера перерывов
npm start           # запустить приложение на компьютере
npm run dist:win    # собрать установщик Windows в папку dist (на Windows)
npm run android:prepare && cd android && ./gradlew assembleDebug   # APK (нужны JDK 17 и Android SDK)
```

## Заметки

- Ключ подписи Android в папке `android-signing` — стандартный отладочный (пароль `android`). Он нужен, чтобы новые сборки
  ставились поверх старых. Для публикации в Google Play сделайте отдельный ключ и храните его в секретах GitHub.
- Упражнения помогают размять и расслабить глаза при долгой работе за экраном. Это не лечение и не замена консультации офтальмолога.
